# Ecommerce_Sales_Analysis
E-Commerce Sales Analytics project using SQL, Python, Tableau to analyze sales performance, customer behaviour, regional trends, product categories, discounts, and delivery performance through data analysis and interactive dashboards.
# 🛒 E-Commerce Sales Analytics

### 📊 Python | 🗄️ SQL | 📈 Tableau

---

## 📌 Project Overview

The **E-Commerce Sales Analytics** project focuses on analyzing e-commerce sales data to understand sales performance, customer behavior, product performance, regional trends, discounts, and delivery performance.

In this project, **Python** is used for data cleaning and exploratory data analysis, **SQL** is used to analyze the data and answer business questions, and **Tableau** is used to create an interactive dashboard for visualizing the results.

The main objective of this project is to transform raw e-commerce data into meaningful insights that can help businesses understand their performance and make data-driven decisions.
